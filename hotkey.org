

* buffer

| 快捷键  | 说明              |
|---------+-------------------|
| C-x x r | 重命名当前 buffer |

* window/frame

| 快捷键  | 说明                  |
|---------+-----------------------|
| C-x 5 2 | 新建 frame            |
| C-x 5 0 | 关闭当前 frame        |
| C-x 5 o | 切换到其他 frame      |
| C-x 5 f | 在新 frame 打开文件 |
| C-x 5 b | 在新 frame 切换 buffer |

* project.el

| 快捷键  | 说明             |
|---------+------------------|
| C-x p p | 切换项目         |
| C-x p f | 查找项目文件     |
| C-x p b | 切换项目 buffer  |
| C-x p s | 在项目中搜索     |
| C-x p g | 在项目中执行 grep |
| C-x p d | 打开项目根目录   |
| C-x p k | 关闭项目 buffers |
| C-x p ! | 在项目中执行命令 |
| C-x p & | 在项目中异步执行命令 |

* magit

| 快捷键  | 说明                  |
|---------+-----------------------|
| C-x g   | 打开 Magit status     |
| s       | stage 当前文件/区块   |
| u       | unstage 当前文件/区块 |
| c c     | 创建 commit           |
| C-c C-c | 完成 commit message   |
| P p     | push 到 upstream      |
| F p     | pull from upstream    |
| b b     | 切换 branch           |
| b c     | 创建 branch           |
| l l     | 查看 log              |
| d d     | 查看 diff             |
| g       | 刷新 Magit buffer     |
| q       | 退出当前 Magit buffer |

* embark

| 快捷键 | 说明                       |
|--------+----------------------------|
| C-.    | 对当前对象执行 Embark 动作 |
| C-;    | 执行 Embark 推荐动作       |
| C-h B  | 显示当前上下文可用动作     |

* consult-eglot

| 快捷键 | 说明                       |
|--------+----------------------------|
| M-g s  | 搜索 LSP workspace symbols |

* treemacs

| 快捷键  | 说明                          |
|---------+-------------------------------|
| C-c t t | 打开/切换 Treemacs 项目树     |
| C-c t f | 在 Treemacs 中定位当前文件    |
| C-c t p | 添加目录到 Treemacs workspace |
| C-c t s | 跳转到 Treemacs 窗口          |
| P       | 开关 Treemacs peek mode       |
| n       | 移动到下一个节点              |
| p       | 移动到上一个节点              |
| M-N     | 向下滚动预览窗口              |
| M-P     | 向上滚动预览窗口              |

* perspective

| 快捷键  | 说明                           |
|---------+--------------------------------|
| C-c w s | 切换/创建 workspace            |
| C-c w k | 删除当前 workspace             |
| C-c w n | 切换到下一个 workspace         |
| C-c w p | 切换到上一个 workspace         |
| C-c w b | 在当前 workspace 中切换 buffer |

* vterm

| 快捷键  | 说明                      |
|---------+---------------------------|
| C-l     | 清空当前屏幕              |
| C-u C-l | 清空当前屏幕和 scrollback |

* org-mode 表格

| 快捷键      | 说明                     |
|-------------+--------------------------|
| C-c C-c     | 格式化/重新对齐当前表格     |
| TAB         | 跳到下一个单元格，并自动对齐 |
| S-TAB       | 跳到上一个单元格，并自动对齐 |
| RET         | 跳到下一行同列             |
| M-<left>    | 当前列左移                |
| M-<right>   | 当前列右移                |
| M-<up>      | 当前行上移                |
| M-<down>    | 当前行下移                |
| M-S-<left>  | 删除当前列                |
| M-S-<right> | 插入新列                  |
| M-S-<up>    | 删除当前行                |
| M-S-<down>  | 插入新行                  |
| C-c -       | 插入水平分隔线             |
