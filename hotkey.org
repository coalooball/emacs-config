

* vterm

| 快捷键  | 说明                      |
|---------+---------------------------|
| C-l     | 清空当前屏幕              |
| C-u C-l | 清空当前屏幕和 scrollback |

* org-mode 表格

| 快捷键      | 说明                     |
|-------------+--------------------------|
| C-c C-c     | 格式化/重新对齐当前表格     |
| TAB         | 跳到下一个单元格，并自动对齐 |
| S-TAB       | 跳到上一个单元格，并自动对齐 |
| RET         | 跳到下一行同列             |
| M-<left>    | 当前列左移                |
| M-<right>   | 当前列右移                |
| M-<up>      | 当前行上移                |
| M-<down>    | 当前行下移                |
| M-S-<left>  | 删除当前列                |
| M-S-<right> | 插入新列                  |
| M-S-<up>    | 删除当前行                |
| M-S-<down>  | 插入新行                  |
| C-c -       | 插入水平分隔线             |
